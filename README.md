# E-commerce Sales Dashboard



**Project Overview**

An interactive e-commerce sales dashboard developed using Microsoft Power BI to analyze sales performance and business trends.



## Tools Used

\- Microsoft Power BI

\- Microsoft Excel / CSV datasets

\- Git and GitHub



## **Project Files**

\- **Ecommerce PowerBI Dahboard.pbix** — Power BI dashboard.

\- **Orders.csv** — Orders dataset.

\- **Details.csv** — Additional sales details dataset.



## Key Metrics and Analysis

\- Sales amount and profit

\- Quantity sold

\- Average order value

\- Product categories and subcategories

\- Customer performance

\- State-wise sales

\- Payment methods

\- Monthly profit trends



###### How to Use

1\. Download the `.pbix` file and both CSV files.

2\. Open the dashboard in Power BI Desktop.

3\. If necessary, update the data source paths to the locations of the downloaded CSV files.

4\. Refresh the data if required.
